Welcome to the Control Panel

Select a script from the left sidebar to execute automated commands, upload data, and manage the kiosk dashboard.

Available Actions

Reminder Editor

Open the live markdown editor to quickly create, edit, or delete slides from the Reminders rotation. Changes are saved instantly.

Equipment Editor

Manage equipment status directly from the web. Add categories, update statuses (OK, OS, PM), and instantly push updates to the Kiosk's Masonry grid.

Track Management & Commodity Rules

Upload daily track checks, vector SVG maps, live edit car counts, and customize commodity keywords and car dash colors.

Shift Schedules

Manage facility work shifts, working days, and hours. Powers the live TV shift countdown progress bar.

Special Event Editor

Set up a high-priority third view that joins the rotation. Perfect for road closures, plant maintenance, or safety drills. Automatically expires.

Site Settings

Configure location-specific details (Site Name, Coordinates, Timezone, Vercel API URL) and manage admin security credentials.

User Accounts & RBAC

Manage employee user accounts, assign role-based permissions (Admin, Maintenance, Viewer), and generate single-use registration invite links.

Security & Operations Audit Logs

Inspect comprehensive audit trails for equipment toggles, configuration changes, runner executions, and user authentications with CSV export.

Extras & Themes

Select display themes, configure per-shift theme dedication, and toggle individual dashboard widgets and features on or off.

Update Production Tracker

Change the actively displayed production metric (e.g. Blend Recipe #, Current Heat #, Active Grade, Daily Target) shown on the dashboard.

Update OSHA Safe Date

Modify the "Date of Last Recordable Incident". The system will automatically calculate the "Days Safe" counter for you.

Override Daily Toolbox

Upload an image to completely replace today's Toolbox Talk slide. It automatically expires at midnight.

Trigger Manual Asset Scan

Force the system to immediately rescan all assets (including employee spreadsheets and tracked JSON metrics).

Restart Kiosk Web App

Restart the Docker container hosting the Kiosk application, instantly refreshing the TV displays.

Reboot Entire System

Perform a hard reboot of the entire Kiosk operating system. Use this if the system becomes entirely unresponsive.

Use the editor below to seamlessly edit your Reminders deck in real-time. Use the 🪄 Magic Words list to supercharge your slides!

How to Edit Reminders

The Reminders widget automatically cycles through your slides. Every slide must start with an H1 Header (using a single hashtag # ). Everything written below an H1 Header belongs to that slide until the next H1 Header begins.

Magic Words Reference

Drop these magic words anywhere below the H1 header of a slide. You can combine multiple magic words on a single slide! The system will automatically detect them, apply the styling, and seamlessly hide the magic word from the final display.

!HIGH

Applies a pulsing Neon Orange glow to the widget border. Perfect for warnings.

!CRITICAL

Applies an aggressive, rapid-pulsing Red glow. Used for immediate safety halts.

!LONG

Pauses the Kiosk rotation loop and holds this slide on the screen for 2 full minutes.

!ONLY

Hides all other slides in the file and exclusively loops any slides containing this magic word.

!SPLIT

Breaks any bulleted or numbered list on the slide into perfectly spaced side-by-side columns.

!LARGE

Boosts the font size of the entire slide by 75%. Great for punchy, one-line announcements.

!CENTER

Centers the text perfectly in the middle of the widget, both vertically and horizontally.

!COUNTDOWN MM-DD-HH-mm

Injects a live countdown timer for a specific date/time (e.g. !COUNTDOWN 12-25-14-30). It assumes the next available matching date.

!QR url

Automatically generates a scannable QR Code for the given link (e.g. !QR https://google.com).

!LIMIT DD-HH

Sets a time limit on the slide (e.g. !LIMIT 07-00 for 7 days). It will automatically convert to an absolute !EXPIRE tag upon saving.

!EXPIRE YYYY-MM-DD-HH

Silently drops the slide from the rotation once the specific date and hour has passed.
